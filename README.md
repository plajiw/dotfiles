# plajiw dotfiles

My personal VS Code configuration: editor/terminal settings and keybindings.

## Install

Requires Git Bash on Windows, or any bash shell on Linux.

```bash
./install.sh
```

This copies `vscode/settings.json` and `vscode/keybindings.json` into VS Code's User folder. Any existing files there are backed up with a `.bak` suffix first.
